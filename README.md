# Ramnesh Kumar Sahu | Portfolio

Personal portfolio website of **Ramnesh Kumar Sahu**, a B.Tech Computer Science (AI/ML) student at PSIT Kanpur and building **SKOT**, a deep-tech UAV airspace management platform. The site presents his work across drones, rocketry, embedded systems, AI and full-stack development.

## About the website

A fast, single-page static site with a black and green terminal-inspired theme and monospace typography. It is fully responsive, with a side social rail on desktop and a menu button on mobile.

## Sections

- **Home**: introduction, portrait and current focus
- **Projects**: SKOT, 7EVEN, MyAlgoBot, R4 Rescue, AcciSense, Sign Language Translator, E-Challan system and model rocketry
- **Skills**: languages, web, AI/ML, embedded, simulation, cloud and APIs
- **Experience**: SKOT, PSIT Vyomnauts, 7EVEN and education, plus competitions (TEKNOFEST 2026, ISRO IN-SPACe, Smart India Hackathon, Bharatiya Antariksh Hackathon) and certifications
- **Resume**: one-click PDF download
- **About me** and **Contact**

## Tech stack

HTML5, CSS3 and vanilla JavaScript in a single `index.html`, with the Fira Code font from Google Fonts. There is no framework and no build step. Hosted on Vercel.

## Repository contents

- `index.html`: the complete website (markup, styles and scripts)
- Project and profile images: `.png` and `.jpeg` files used by the project cards and photo slots
- `Ramnesh_Kumar_Sahu_CV.pdf`: resume offered for download
- `favicon.ico`, `favicon-32.png`, `favicon-512.png`, `apple-touch-icon.png`: browser tab and device icons
- `vercel.json`: hosting configuration
- `assets/`: spare folder for additional media
